# Ejercicios: Introducción y Fundamentos de R

Este repositorio contiene las soluciones a los ejercicios prácticos del módulo de Introducción a R.

## 📋 Contenido de los ejercicios
El script `Solucion_Ejercicios_R.R` incluye la resolución de los siguientes conceptos básicos:

* **Variables y Tipos de Datos:** Definición de variables numéricas y de texto.
* **Vectores y Listas:** Creación y manipulación de estructuras de datos.
* **Operaciones:** Aritméticas (+, *) y Lógicas (TRUE/FALSE).
* **Funciones Básicas:** Uso de `class()`, `is.numeric()`, etc.
* **Comparaciones:** Uso de operadores como `%in%` y comparadores lógicos.

## 🛠️ Cómo ejecutar el código
1.  Descarga el archivo `.R`.
2.  Ábrelo en **RStudio**.
3.  Selecciona el código y pulsa `Run` (o `Ctrl + Enter`).
